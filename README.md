# Visual Clustering Approach for Molecular Docking Results 🧬

## Project Overview

This project presents a visual approach for exploring and interpreting molecular docking results generated with Vina and AutoDock.

The work was developed as part of my Computer Systems Engineering research and combines data processing, clustering, and visualization techniques to help analyze large amounts of molecular docking information.

This project was also presented as published research.

---

## Problem

Molecular docking experiments can generate large amounts of data representing possible interactions and positions between molecules.

Analyzing these results can become difficult when the information is reviewed only as raw numerical output.

The project explored how computational and visual techniques could be used to organize docking results and make patterns within the data easier to identify and interpret.

---

## Objective

The main objective was to develop a visual clustering approach for molecular docking results from Vina and AutoDock.

The project focused on:

- Processing molecular docking data.
- Organizing results using clustering techniques.
- Exploring relationships and patterns within the results.
- Using visualization to make complex information easier to interpret.

---

## Approach

The project combined programming, data processing, clustering, and visualization.

Molecular docking results were processed and organized so that similar information could be grouped and explored visually.

Visualization techniques were then used to provide another way of examining the results beyond raw numerical outputs.

This project was one of my first experiences using programming and data analysis to solve a complex research problem.
